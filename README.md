# pico-temp-logger

Temperature logger on a Raspberry Pi Pico 2 (RP2350) with two DS18B20 probes, a hand-written 1-Wire driver, and logging to onboard flash.

**Status:** in progress. See [LOG.md](LOG.md) for dated progress.

## Hardware

- Raspberry Pi Pico 2 (non-W), pre-soldered headers
- 2x DS18B20 waterproof probes (DROK), 4.7 kΩ pull-up on the data line
- Breadboard and jumpers
